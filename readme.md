# 27W LED load in a flyback converter with a solution for ripple current (Simulink simulation implementation)

27W LED load inverter with a ripple current solution
The inverter is fundamentally based on the concept of a ripple current port, reducing the size of output capacitor C1 from 2.4mH to 400uH.
The ripple port switch S2 operates at 100Hz, while the main switch S1 operates at 60kHz. The output capacitor C1 in this inverter only filters the ripple frequency of the main current but does not filter the double supply frequency at zero crossover points. Therefore, the value of C1 can be significantly reduced. The ripple port filters the double supply frequency component and balances the power output for the LEDs.
